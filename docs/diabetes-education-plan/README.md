# Diabetes Education — 100-Day Social Media Plan

This folder contains a complete 100-day content plan for a Pharm.D + MSc Diabetes Care & Management creator who wants to publish on Instagram (1–2 minute Reels) and YouTube (5–6 minute videos).

## Files

| File | What it is |
|---|---|
| `diabetes_100day_plan.md` | Master document. ~95,000 words. Every day's hook lines, scripts, references, B-roll notes, captions. |
| `diabetes_100day_plan.html` | Same content, styled for printing. **Open in any browser → Ctrl+P → Save as PDF** to get the final PDF. |
| `build_html.py` | The Python script that converted the Markdown to HTML. Re-run it after editing the `.md`. |

## How to get a PDF

1. Open `diabetes_100day_plan.html` in Chrome / Edge / Firefox.
2. Press **Ctrl + P** (or **Cmd + P** on Mac).
3. Choose **Save as PDF**, paper size A4 or Letter, default margins.
4. Save anywhere on your computer.

## What's inside

- **Mission, audience, brand voice** — the editorial spine of the channel.
- **Copyright-safe production guide** — music, B-roll, citations, disclaimer templates, pre-publish checklist.
- **100-day roadmap** organised into 10 themed phases:
  1. Foundations
  2. Pathophysiology decoded
  3. Diet myths and truths (Indian plate)
  4. Movement / exercise prescription
  5. Yoga, sleep, stress, mind
  6. Pharmacology demystified (one drug class per day)
  7. Reversal and remission — the honest truth
  8. Complications and prevention
  9. Special populations (pregnancy, kids, elderly, Ramadan)
  10. Misinformation and your action plan
- **Days 1–14** — full word-for-word scripts (Instagram + YouTube, timed).
- **Days 15–100** — structured beat-sheets you flesh out using the Day 1–14 tone template.
- **~210 peer-reviewed references** cited inline (Lancet, NEJM, JAMA, Diabetes Care, BMJ, Nature, Cell, Diabetologia, ICMR-INDIAB, DiRECT, EMPA-REG, STEP/SURMOUNT/SURPASS, ADA Standards of Care 2024, KDIGO 2022, ACOG, DIPSI, ICMR-NIN, FSSAI).
- **Master bibliography** — deduplicated and ready for video descriptions.
- **10 figure / flowchart specifications** you build in Canva to stay copyright-safe.
- **Hashtag bank, posting calendar, analytics tracker, repurposing matrix.**
- **30-day pre-launch checklist.**

## Disclaimer

This is general health-education content. It is not a substitute for personalised medical advice. Every video should carry a disclaimer telling viewers to consult their physician, pharmacist, or qualified diabetes educator before changing diet, exercise, or medication. All scientific claims must be linked to the cited references in the description.

## Copyright

All script content is original. No copyrighted lyrics, footage, or third-party text are included. References are cited only by author and journal — citing a source is fair use. Re-create all flowcharts and tables in Canva using the descriptions provided.
